# Personal Portfolio

A responsive portfolio covering cloud engineering, DevOps, security, AI projects, AWS certifications, and reviewing and judging work.

Built with HTML, CSS, and JavaScript. No build step is required.

## Local preview

From this directory, run:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Open http://127.0.0.1:8000/ in your browser.

## GitHub Pages

The site is intended for https://rohitjain2021.github.io/.

In repository Settings ? Pages, select **Deploy from a branch**, branch **main**, and folder **/(root)**.

## Files

- `index.html`: portfolio content and navigation.
- `assets/css/style.css`: dark theme, responsive layout, and typography.
- `assets/js/script.js`: typewriter animation, active navigation, and footer year.
- `assets/rohit-jain.jpg`: profile photo.
- `.nojekyll`: serves the static files without Jekyll processing.

Animation respects reduced-motion preferences. Page content remains readable without JavaScript.
